# Recette fonctionnelle

Cocher après essai dans l'installation cible, pas avant.

- [ ] La construction Docker se termine sans erreur et le service est healthy.
- [ ] L'ouverture depuis le PC demande le mot de passe et affiche Valen Learning sombre/orange.
- [ ] Le site s'ouvre depuis un deuxième PC et le téléphone avec l'adresse du serveur.
- [ ] L'ajout d'un mot depuis le téléphone apparaît après actualisation sur le PC.
- [ ] La modification et le favori d'un mot sont conservés après rechargement.
- [ ] Les cartes mémoire, QCM et traductions écrites enregistrent leurs résultats.
- [ ] Le bouton haut-parleur fonctionne avec une voix anglaise sur chaque appareil.
- [ ] L'import d'un CSV ajoute les nouvelles paires sans effacer les paires existantes.
- [ ] La sauvegarde complète contient les onze CSV et s'ouvre sans erreur.
- [ ] Un redémarrage Docker conserve le carnet et les résultats.
- [ ] Les deux leçons de départ sont lisibles sans clé IA.
- [ ] Une demande IA avec une clé valide crée le contenu attendu et augmente le compteur local.
- [ ] Un cours IA se rouvre et son quiz se rejoue sans augmenter le compteur IA.
- [ ] Le texte d'une correction est consultable après rechargement.
- [ ] Une clé absente ou invalide affiche une erreur compréhensible sans perdre le carnet.

La validation de l'accès distant et du chiffrement doit être faite séparément avant une exposition hors du réseau local.

## Bibliothèque v3

- [ ] Deux onglets, Vocabulaire et Grammaire, lisibles sur PC et téléphone.
- [ ] Import avec aperçu, confirmation, bilan et erreur claire pour un mauvais type.
- [ ] Réimport du même CSV sans doublon ni perte de progression.
- [ ] Statut de fiche conservé au redémarrage.
- [ ] Lecture du dossier imports sans reconstruction de l'image.
- [ ] Jeux lancés depuis une collection limités aux mots de cette collection.
